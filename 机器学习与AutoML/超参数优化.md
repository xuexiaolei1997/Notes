# 超参数优化实战指南 (Hyperparameter Optimization)

在机器学习与算法建模中，超参数优化（HPO）是决定模型上限与泛化能力的关键步骤。本文档汇总主流超参数调优工具的实战代码模板与最佳实践。

---

## 1. Optuna 实战 (推荐：工业界标准)

[Optuna](https://optuna.org/) 是目前业界最流行、生态最完善的超参数优化框架。采用 Tree-structured Parzen Estimator (TPE) 算法，原生支持剪枝（Pruning）、多目标寻优及分布式持久化。

### 1.1 基础调优与交叉验证 (LightGBM 示例)
```python
import optuna
import numpy as np
from lightgbm import LGBMRegressor
from sklearn.model_selection import KFold
from sklearn.metrics import root_mean_squared_error

def objective(trial: optuna.Trial) -> float:
    # 1. 动态定义参数搜索空间 (支持 suggest_int, suggest_float, suggest_categorical)
    params = {
        "n_estimators": trial.suggest_int("n_estimators", 50, 300, step=10),
        "learning_rate": trial.suggest_float("learning_rate", 1e-3, 0.3, log=True),
        "num_leaves": trial.suggest_int("num_leaves", 15, 127),
        "max_depth": trial.suggest_int("max_depth", 3, 12),
        "min_child_samples": trial.suggest_int("min_child_samples", 5, 50),
        "subsample": trial.suggest_float("subsample", 0.5, 1.0),
        "colsample_bytree": trial.suggest_float("colsample_bytree", 0.5, 1.0),
        "random_state": 42,
        "verbose": -1,
    }

    # 2. 5 折交叉验证评估
    kf = KFold(n_splits=5, shuffle=True, random_state=42)
    scores = []
    
    for train_idx, val_idx in kf.split(X, y):
        X_tr, y_tr = X[train_idx], y[train_idx]
        X_va, y_va = X[val_idx], y[val_idx]

        model = LGBMRegressor(**params)
        model.fit(X_tr, y_tr)
        
        preds = model.predict(X_va)
        rmse = root_mean_squared_error(y_va, preds)
        scores.append(rmse)

    return np.mean(scores)

# 3. 创建 Study 并执行优化 (direction="minimize" 最小化损失)
study = optuna.create_study(
    direction="minimize",
    sampler=optuna.samplers.TPESampler(seed=42),
    pruner=optuna.pruners.MedianPruner()  # 自动早停剪枝不佳的试验
)
study.optimize(objective, n_trials=50, timeout=600)

print(f"最佳损失 (RMSE): {study.best_value:.4f}")
print("最佳参数组合:")
for k, v in study.best_params.items():
    print(f"  {k}: {v}")
```

## 2. Bayesian-Optimization (`bayes_opt`)

基于高斯过程回归（Gaussian Process）的经典贝叶斯优化库：

```python
from bayes_opt import BayesianOptimization
from lightgbm import LGBMRegressor
from sklearn.metrics import mean_absolute_percentage_error

# 1. 定义连续搜索边界 (bayes_opt 原生仅支持浮点边界)
pbounds = {
    'num_leaves': (15, 127),
```

## 3. Scikit-Optimize (`skopt`)

`scikit-optimize` 是与 Scikit-Learn 深度集成的贝叶斯优化库，支持 `gp_minimize`（高斯过程）、`forest_minimize`（随机森林）及 `gbrt_minimize`：

```python
from skopt import gp_minimize
from skopt.space import Integer, Real
from skopt.utils import use_named_args
from lightgbm import LGBMRegressor
from sklearn.metrics import mean_absolute_percentage_error

# 1. 显式定义参数空间及类型
space = [
    Integer(15, 127, name='num_leaves'),
    Integer(3, 12, name='max_depth'),
    Real(0.01, 0.3, "log-uniform", name='learning_rate'),
    Integer(50, 300, name='n_estimators')
]

# 2. 定义目标函数 (使用 @use_named_args 接收关键字参数)
@use_named_args(space)
def score_func(**params):
    model = LGBMRegressor(**params, random_state=42, verbose=-1)
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)
    return mean_absolute_percentage_error(y_test, y_pred)

# 3. 运行高斯过程优化
res = gp_minimize(score_func, space, n_calls=30, random_state=42, verbose=False)

# 4. 提取最佳参数
best_params = {dim.name: val for dim, val in zip(space, res.x)}
print("最佳参数:", best_params)
print(f"最低 MAPE: {res.fun:.4f}")
```

## 4. 主流调优框架选型对比

| 工具 | 核心算法 | 适用场景 | 优势 | 劣势 |
| :--- | :--- | :--- | :--- | :--- |
| **Optuna** | TPE / CMA-ES / GP | 绝大多数通用 ML / DL 调优 | 生态完善、支持剪枝早停、支持 SQLite 持久化与可视化 Dashboard | 需要编写 Objective 函数 |
| **FLAML** | BlendSearch / CFO | 快速建模、低算力预算预算调优 | 经济高效、内置主流模型与自动特征预处理 | 自定义极复杂 Pipeline 时稍重 |
| **Bayes-Opt** | 高斯过程 (GP) | 低维连续参数调优 | 算法经典、数学原理直观 | 仅支持连续浮点边界、难以处理类别变量 |
| **Skopt** | GP / RF / GBDT | 与 Scikit-Learn Pipeline 深度结合 | 支持多种 Surrogate 模型 | 社区更新较慢、大规模并行支持较弱 |
