# Shell echo 命令与终端输出

`echo` 是 Shell 中最常用的输出文本与变量内容的内置命令。

---

## 1. 常用参数与基础用法

### 核心参数
- **`-e`**：激活转义字符（如 `\n`, `\t`, `\c` 等）。
- **`-n`**：输出后**不换行**。

### 基础输出示例
```bash
# 1. 输出普通字符串 (带不带引号均可，推荐带引号)
echo "Hello, Shell!"

# 2. 输出变量与转义双引号
user="admin"
echo "当前用户: \"$user\""

# 3. 原样输出 (单引号强引用，不解析变量与转义符)
echo '$user\n'  # 输出: $user\n

# 4. 换行与不换行输出
echo -e "Line 1\nLine 2"    # -e 开启换行解析
echo -n "请输入用户名: "     # -n 不自动换行 (常用于交互提示)

# 5. 执行命令并输出结果 (命令替换 $() 或反引号)
echo "当前时间: $(date '+%Y-%m-%d %H:%M:%S')"
```

## 2. 生产实战：彩色终端输出 (ANSI Escape Codes)

在编写自动化运维或部署脚本时，使用颜色可以显著提高日志可读性：

```bash
#!/bin/bash

# 定义颜色常量
COLOR_RED="\033[31m"
COLOR_GREEN="\033[32m"
COLOR_YELLOW="\033[33m"
COLOR_BLUE="\033[34m"
COLOR_RESET="\033[0m"

# 彩色日志封装
log_info()    { echo -e "${COLOR_BLUE}[INFO]${COLOR_RESET} $1"; }
log_success() { echo -e "${COLOR_GREEN}[SUCCESS]${COLOR_RESET} $1"; }
log_warn()    { echo -e "${COLOR_YELLOW}[WARN]${COLOR_RESET} $1"; }
log_error()   { echo -e "${COLOR_RED}[ERROR]${COLOR_RESET} $1"; }

# 调用示例
log_info "正在启动服务..."
log_warn "内存占用高于 80%"
log_success "模型权重下载完成！"
log_error "数据库连接失败！"
```

## 3. 重定向输出至文件

```bash
# 覆盖写入到文件
echo "VERSION=1.0.0" > version.txt

# 追加写入到文件末尾
echo "$(date) - Task Completed" >> task.log
```
