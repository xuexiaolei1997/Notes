# Shell test 条件测试命令

`test` 命令用于检查某个条件是否成立，返回状态码 `0`（真/成功）或非 `0`（假/失败）。

在 Shell 中，**`test expression` 与 `[ expression ]` 完全等价**（方括号实质上是 `test` 命令的别名，因此中括号两边必须有空格）。

---

## 1. 数值比较测试

> 仅用于整数比较：

| 参数 | 说明 | test 语法示例 | [ ] 语法等价示例 |
| :---: | :--- | :--- | :--- |
| **`-eq`** | 等于 (Equal) | `test $a -eq $b` | `[ $a -eq $b ]` |
| **`-ne`** | 不等于 (Not Equal) | `test $a -ne $b` | `[ $a -ne $b ]` |
| **`-gt`** | 大于 (Greater Than) | `test $a -gt $b` | `[ $a -gt $b ]` |
| **`-ge`** | 大于等于 (Greater or Equal) | `test $a -ge $b` | `[ $a -ge $b ]` |
| **`-lt`** | 小于 (Less Than) | `test $a -lt $b` | `[ $a -lt $b ]` |
| **`-le`** | 小于等于 (Less or Equal) | `test $a -le $b` | `[ $a -le $b ]` |

---

## 2. 字符串测试

| 参数 | 说明 | 示例 |
| :---: | :--- | :--- |
| **`=`** / **`==`** | 字符串内容相等 | `test "$str1" = "$str2"` |
| **`!=`** | 字符串内容不相等 | `test "$str1" != "$str2"` |
| **`-z`** | 字符串长度为 0 (为空) | `test -z "$str"` |
| **`-n`** | 字符串长度大于 0 (非空) | `test -n "$str"` |

---

## 3. 文件属性测试

| 参数 | 说明 | 实战示例 |
| :---: | :--- | :--- |
| **`-e`** | 文件或目录存在 (Exist) | `test -e /etc/passwd` |
| **`-f`** | 文件存在且为普通文件 (File) | `test -f config.yaml` |
| **`-d`** | 文件存在且为目录 (Directory) | `test -d /var/log` |
| **`-r`** | 文件存在且当前用户可读 | `test -r data.csv` |
| **`-w`** | 文件存在且当前用户可写 | `test -w app.log` |
| **`-x`** | 文件存在且当前用户可执行 | `test -x build.sh` |
| **`-s`** | 文件存在且大小大于 0 | `test -s output.json` |
| **`-L`** | 文件存在且为软链接 | `test -L /bin/sh` |

---

## 4. 生产实战：利用 test 简化条件执行

在 Shell 脚本中，常结合逻辑运算符 `&&`（成功时执行）与 `||`（失败时执行）来实现紧凑的代码逻辑：

```bash
# 文件不存在则创建
test -d "./logs" || mkdir -p "./logs"

# 配置文件存在才启动服务，否则报错退出
test -f "config.env" && source "config.env" || { echo "缺失配置文件！"; exit 1; }
```
