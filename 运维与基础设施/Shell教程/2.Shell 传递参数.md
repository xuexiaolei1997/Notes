# Shell 参数传递与特殊变量

执行 Shell 脚本时，可以向脚本传递参数。在脚本内部通过特定变量即可捕获并处理这些输入。

---

## 1. 位置参数与特殊变量

| 变量 | 说明 | 示例 / 说明 |
| :--- | :--- | :--- |
| **`$0`** | 当前执行的脚本名称/路径 | `./deploy.sh` |
| **`$1` ~ `$9`** | 第 1 到第 9 个位置参数 | `$1` 即第一个参数 |
| **`${10}`** | 第 10 个及以上的参数必须用花括号包裹 | `${10}`, `${11}` |
| **`$#`** | 传递给脚本或函数的参数总个数 | 常用于判断参数是否合法：`if [ $# -lt 2 ]; then ...` |
| **`$*`** | 以单个字符串形式展示所有参数 | `"$1 $2 $3"` |
| **`$@`** | 将每个参数作为独立的引用字符串返回 (推荐) | `"$1" "$2" "$3"` |
| **`$?`** | 上一条命令的退出状态码 | **0 为执行成功**，非 0（如 1~255）表示错误 |
| **`$$`** | 当前运行脚本的进程 ID (PID) | 常用于生成唯一临时文件：`/tmp/task_$$.log` |
| **`$!`** | 后台运行的最后一个进程的 PID | 如 `python train.py &` 后通过 `$!` 捕获其 PID |

---

## 2. 核心区别：`"$*"` vs `"$@"`

在没有双引号时，`$*` 与 `$@` 行为相同。但在加上双引号后，两者有本质区别：

```bash
#!/bin/bash

echo "--- 演示 \"\$*\" (合并为一个整体) ---"
for arg in "$*"; do
    echo "Arg: $arg"
done

echo "--- 演示 \"\$@\" (保留各个独立参数，推荐) ---"
for arg in "$@"; do
    echo "Arg: $arg"
done
```

**执行与输出：**
```bash
$ bash test.sh "hello world" "python" "shell"

--- 演示 "$*" ---
Arg: hello world python shell   # 只循环 1 次

--- 演示 "$@" ---
Arg: hello world                # 循环 3 次，完整保留带空格参数
Arg: python
Arg: shell
```

## 3. 参数左移操作 (`shift`)

`shift [n]` 命令用于将参数列表整体向左移动 n 位（默认为 1），常用于遍历处理未知数量的参数：

```bash
#!/bin/bash

while [ $# -gt 0 ]; do
    echo "正在处理参数: $1"
    shift  # 弹出第一个参数，$2 变成新的 $1
done
```

## 4. 生产实战：`getopts` 解析命令行选项

使用 `getopts` 解析类似 `-h`、`-p <port>`、`-e <env>` 的短选项参数：

```bash
#!/bin/bash

# 选项后的冒号表示该选项需要接参数值 (如 p: 和 e:)
while getopts "hp:e:" opt; do
    case $opt in
        h)
            echo "用法: $0 [-p port] [-e environment]"
            exit 0
            ;;
        p)
            PORT=$OPTARG
            ;;
        e)
            ENV=$OPTARG
            ;;
        \?)
            echo "无效选项: -$OPTARG" >&2
            exit 1
            ;;
    esac
done

echo "部署环境: ${ENV:-dev}, 服务端口: ${PORT:-8080}"
```
