# Shell printf 命令与格式化输出

`printf` 比 `echo` 更加强大和具备可移植性，其语法与 C 语言中的 `printf` 函数高度一致，支持精细的**文本对齐、浮点数精度控制与格式化表格输出**。

---

## 1. 基本语法与格式说明符

```bash
printf "format-string" [arguments...]
```

### 常用格式说明符
| 格式符 | 说明 | 示例 |
| :---: | :--- | :--- |
| **`%s`** | 字符串 (String) | `printf "%s\n" "hello"` |
| **`%d` / `%i`** | 十进制整数 (Integer) | `printf "%d\n" 42` |
| **`%f`** | 浮点数 (Float) | `printf "%.2f\n" 3.14159` -> `3.14` |
| **`%c`** | 单个字符 (Char) | `printf "%c\n" 65` -> `A` |
| **`%x` / `%X`** | 十六进制整数 (Hex) | `printf "%X\n" 255` -> `FF` |
| **`%%`** | 输出一个字面百分号 `%` | `printf "%d%%\n" 80` -> `80%` |

---

## 2. 宽度、对齐与精度控制

```bash
# 1. 默认右对齐 (指定宽度为 10)
printf "%10s : %5d\n" "CPU" 85

# 2. 左对齐 (- 号表示左对齐)
printf "%-10s : %-5d\n" "CPU" 85

# 3. 浮点数保留两位小数
printf "GPU 利用率: %6.2f%%\n" 98.456   # GPU 利用率:  98.46%

# 4. 整数前导补零
printf "文件序号: %04d\n" 7            # 文件序号: 0007
```

## 3. 实战案例：生成格式化运维报表

```bash
#!/bin/bash

# 打印表头
printf "%-15s %-12s %-10s %-10s\n" "SERVICE" "STATUS" "CPU(%)" "MEM(MB)"
printf "%-15s %-12s %-10s %-10s\n" "---------------" "------------" "----------" "----------"

# 打印数据行
printf "%-15s %-12s %-10.1f %-10d\n" "nginx" "running" 1.5 64
printf "%-15s %-12s %-10.1f %-10d\n" "redis" "running" 0.8 128
printf "%-15s %-12s %-10.1f %-10d\n" "model_service" "running" 78.4 2048
printf "%-15s %-12s %-10.1f %-10d\n" "thingsboard" "stopped" 0.0 0
```

**输出效果：**
```text
SERVICE         STATUS       CPU(%)     MEM(MB)   
--------------- ------------ ---------- ----------
nginx           running      1.5        64        
redis           running      0.8        128       
model_service   running      78.4       2048      
thingsboard     stopped      0.0        0         
```

## 4. `printf` 与 `echo` 核心区别

1. **自动换行**：`echo` 默认在末尾追加换行符；`printf` **不会自动换行**，必须显式加上 `\n`。
2. **转义处理**：`echo` 需要 `-e` 开启转义；`printf` **原生支持转义字符**（如 `\n`, `\t`）。
3. **格式化能力**：`printf` 支持任意对齐、精度、前导补零与占位符替换，是生成规整日志和报表的最佳选择。
