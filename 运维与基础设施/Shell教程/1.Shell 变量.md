# Shell 基础与变量操作

Shell 既是一种命令语言，又是一种程序设计语言。通过编写 Shell 脚本，可以高效自动化执行 Linux 命令与系统运维任务。

---

## 1. 变量定义与使用规则

### 1.1 命名规范
- **字符构成**：只能包含字母、数字和下划线 `_`，大小写敏感。
- **开头限制**：不能以数字开头。
- **等号无空格**：定义变量时，**等号 `=` 两侧绝对不能有空格**（如 `name="value"` 是正确的，`name = "value"` 会报错）。
- **命名习惯**：普通变量用小写加下划线（如 `log_dir`），全局环境变量或常量建议全大写（如 `MAX_SIZE=512`）。
- **定义时不加 `$`**：定义或赋值时变量名前不加 `$`，读取变量值时才加 `$`。

### 1.2 变量定义、读取与删除
```bash
# 1. 定义变量
name="Antigravity"

# 2. 读取变量 (推荐使用 ${var} 语法，边界清晰)
echo "Hello, $name"
echo "Hello, ${name}_v2"

# 3. 只读变量 (readonly)
readonly PI=3.14159
# PI=3.14  # 会报错：PI: readonly variable

# 4. 删除变量 (unset，不能删除只读变量)
unset name
echo "name is: $name"  # 输出为空
```

## 2. 变量类型与声明 (declare / typeset)

Shell 默认所有变量均为字符串类型。可通过 `declare` 或 `typeset` 声明特定类型：

```bash
# 声明普通整型变量 (-i)
declare -i count=10
count=count+5
echo "count: $count"  # 15

# 声明只读变量 (-r)
declare -r MAX_CONNECTIONS=100

# 声明普通索引数组 (-a)
declare -a num_list=(1 2 3 4 5)

# 声明关联数组 (-A，即字典/哈希表)
declare -A user_info
user_info["name"]="Alice"
user_info["role"]="Admin"
```

## 3. 字符串核心操作

### 3.1 单引号 vs 双引号
- **单引号 (`''`)**：强引用，内部所有字符原样输出，**不解析变量**，也不能出现未转义的单引号。
- **双引号 (`""`)**：弱引用，**解析变量**和转义字符（如 `\n`, `\t`）。

```bash
user="root"
echo 'Hello, $user'   # 输出: Hello, $user
echo "Hello, $user"   # 输出: Hello, root
```

### 3.2 字符串长度、切片与查找
```bash
str="Linux_Shell_Scripting"

# 1. 获取字符串长度: ${#string}
echo "长度: ${#str}"  # 21

# 2. 截取子字符串: ${string:start:length} (索引从 0 开始)
echo "${str:0:5}"    # 截取前5个字符: Linux
echo "${str:6}"      # 从索引6截取到末尾: Shell_Scripting

# 3. 字符串替换
echo "${str/Shell/Bash}"    # 替换第一个匹配: Linux_Bash_Scripting
echo "${str//i/I}"          # 替换全部匹配: LInux_Shell_ScrIptIng

# 4. 字符串截断 (前缀/后缀匹配)
path="/var/log/nginx/access.log"
echo "${path#*/}"    # 最短非贪婪前缀删除 -> var/log/nginx/access.log
echo "${path##*/}"   # 最长贪婪前缀删除 (提取文件名) -> access.log
echo "${path%.*}"    # 最短非贪婪后缀删除 (提取无后缀路径) -> /var/log/nginx/access
```

### 3.3 变量默认值与容错扩展 (生产高频)
```bash
# 若变量未设置或为空，则返回默认值 (变量本身不变)
port=${PORT:-8080}
echo "使用端口: $port"

# 若变量未设置或为空，则将默认值赋给变量
${DB_HOST:=localhost}
echo "数据库地址: $DB_HOST"

# 若变量未设置，则抛出异常并终止脚本
: ${LOG_DIR:?"错误: 必须指定 LOG_DIR 环境变量"}
```

## 4. Shell 注释与 Here 文档

### 4.1 单行注释
```bash
# 这是一行单行注释
echo "Run task"
```

### 4.2 多行注释 (使用空命令 `:` 与 Here Document)
```bash
: << 'EOF'
这里是多行注释内容
无论写多少行、包含什么特殊符号
都不会被 Shell 解释器执行
EOF

: '
这也是一种常见的多行注释简写形式
'
```
