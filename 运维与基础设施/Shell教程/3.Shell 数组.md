# Shell 数组（索引数组与关联数组）

Bash 支持两种数组类型：
1. **普通索引数组 (Indexed Array)**：以整数为索引下标（从 0 开始）。
2. **关联数组 (Associative Array)**：以字符串为键名（键值对/字典），从 Bash 4.0 开始支持。

---

## 1. 普通索引数组

### 1.1 定义与初始化
```bash
# 方式 1：整体初始化 (空格分隔)
fruits=("apple" "banana" "cherry")

# 方式 2：分行书写
servers=(
    "192.168.1.10"
    "192.168.1.11"
    "192.168.1.12"
)

# 方式 3：指定索引赋值 (下标可不连续)
array[0]="val0"
array[3]="val3"
```

### 1.2 访问、修改与追加
```bash
# 访问单个元素
echo "第一个元素: ${fruits[0]}"  # apple

# 获取所有元素
echo "全部元素: ${fruits[@]}"    # apple banana cherry

# 获取数组长度
echo "元素个数: ${#fruits[@]}"   # 3

# 追加元素
fruits+=("orange" "grape")

# 删除单个元素或清空数组
unset fruits[1]     # 删除索引为 1 的元素
unset fruits        # 清空整个数组
```

### 1.3 数组切片与截取
```bash
numbers=(10 20 30 40 50 60)

# 从索引 1 开始截取 3 个元素: ${array[@]:start:length}
echo "${numbers[@]:1:3}"  # 20 30 40
```

### 1.4 遍历索引数组
```bash
# 方式 1：直接遍历所有元素
for item in "${fruits[@]}"; do
    echo "Fruit: $item"
done

# 方式 2：通过索引下标遍历
for index in "${!fruits[@]}"; do
    echo "Index $index -> Value ${fruits[$index]}"
done
```

## 2. 关联数组 (字典 / 映射)

> **注意**：关联数组**必须先显式使用 `declare -A` 声明**，且赋值时等号两侧不能有空格。

### 2.1 声明与赋值
```bash
# 显式声明关联数组
declare -A app_config

# 单个键值赋值
app_config["host"]="127.0.0.1"
app_config["port"]="8080"
app_config["env"]="production"

# 或者整体初始化
declare -A user_info=(
    ["username"]="admin"
    ["email"]="admin@example.com"
    ["role"]="superadmin"
)
```

### 2.2 常用操作与遍历
```bash
# 获取单个值
echo "Host: ${app_config["host"]}"

# 获取所有值 (${array[@]})
echo "所有配置项值: ${app_config[@]}"

# 获取所有键名 (${!array[@]})
echo "所有配置项键: ${!app_config[@]}"

# 获取元素数量
echo "配置项数量: ${#app_config[@]}"

# 遍历关联数组 (键值对遍历)
for key in "${!app_config[@]}"; do
    echo "Config: $key = ${app_config[$key]}"
done
```

---

## 3. 数组操作常用速查表

| 操作需求 | 语法规则 |
| :--- | :--- |
| **获取所有元素** | `"${array[@]}"` 或 `"${array[*]}"` |
| **获取所有索引/键名** | `"${!array[@]}"` |
| **获取数组元素个数** | `"${#array[@]}"` |
| **获取某个元素的字符长度** | `"${#array[i]}"` |
| **数组切片截取** | `"${array[@]:start:length}"` |
| **向数组尾部追加元素** | `array+=("new_item1" "new_item2")` |
| **删除指定索引元素** | `unset array[i]` |
