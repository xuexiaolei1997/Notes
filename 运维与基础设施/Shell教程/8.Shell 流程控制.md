# Shell 流程控制语句

Shell 提供了丰富的流程控制语句，包括条件分支（`if-elif-else`、`case`）与循环结构（`for`、`while`、`until`），以及循环中断（`break`、`continue`）。

---

## 1. 条件分支语句

### 1.1 `if` / `elif` / `else`
```bash
#!/bin/bash

read -p "请输入分数值 (0-100): " score

if [ "$score" -ge 90 ]; then
    echo "优秀 (Grade A)"
elif [ "$score" -ge 80 ]; then
    echo "良好 (Grade B)"
elif [ "$score" -ge 60 ]; then
    echo "及格 (Grade C)"
else
    echo "不及格 (Grade D)"
fi
```

### 1.2 单行 `if` 结构
在终端或快速脚本中，可用分号 `;` 写在同一行：
```bash
if [ -f "/var/log/app.log" ]; then echo "日志文件存在"; fi
```

## 2. `case ... esac` 多分支模式匹配

类似于 C/Java 的 `switch...case`，特别适合处理用户菜单交互与命令行参数分支：

```bash
#!/bin/bash

read -p "请输入操作指令 (start|stop|restart|status): " action

case "$action" in
    start)
        echo "正在启动服务..."
        ;;
    stop)
        echo "正在停止服务..."
        ;;
    restart)
        echo "正在重启服务..."
        ;;
    status)
        echo "检查服务运行状态..."
        ;;
    *)
        echo "无效指令: $action，请输入 start|stop|restart|status"
        exit 1
        ;;
esac
```

## 3. 循环结构

### 3.1 `for` 循环

**方式 A：列表遍历 (遍历元素、文件或输出)**
```bash
# 遍历列表
for fruit in "apple" "banana" "orange"; do
    echo "水果: $fruit"
done

# 遍历当前目录下的所有 .log 文件
for log_file in *.log; do
    echo "处理日志: $log_file"
done

# 遍历数字序列 {start..end..step}
for i in {1..10..2}; do
    echo "奇数: $i"
done
```

**方式 B：C 语言风格三段式循环**
```bash
for (( i = 1; i <= 5; i++ )); do
    echo "Count: $i"
done
```

### 3.2 `while` 循环
当条件为**真 (True)** 时持续执行循环体：

```bash
count=1
while [ $count -le 5 ]; do
    echo "当前计数: $count"
    (( count++ ))
done

# 按行读取文件内容的经典 while 循环
while IFS= read -r line; do
    echo "Line: $line"
done < "data.txt"

# 死循环结构
while true; do
    echo "Heartbeat..."
    sleep 5
done
```

### 3.3 `until` 循环
与 `while` 相反，当条件为**假 (False)** 时执行，直到条件为真时退出：

```bash
# 等待某个文件生成
until [ -f "/tmp/lock.done" ]; do
    echo "等待完成信号文件..."
    sleep 2
done
echo "检测到信号文件，继续执行！"
```

## 4. 循环控制：`break` 与 `continue`

- **`break [n]`**：跳出当前循环（或跳出外层 n 层循环）。
- **`continue [n]`**：跳过本次迭代剩余代码，直接进入下一次循环。

```bash
for i in {1..10}; do
    if [ $i -eq 3 ]; then
        echo "跳过 $i"
        continue
    fi
    
    if [ $i -eq 7 ]; then
        echo "达到 $i，终止循环"
        break
    fi
    
    echo "处理编号: $i"
done
```
