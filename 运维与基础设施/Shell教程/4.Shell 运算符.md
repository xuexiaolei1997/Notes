# Shell 常用运算符详解

Shell 支持多种运算符：**算术运算符**、**关系运算符**、**布尔/逻辑运算符**、**字符串运算符** 和 **文件测试运算符**。

---

## 1. 算术运算符

在 Bash 中进行数学计算主要有以下方式，**强烈推荐使用 `$(( ))` 算术扩展**（现代、高效、无需调用外部进程）：

### 1.1 算术运算方式对比
```bash
a=10
b=20

# 推荐 1：$(( ... )) 语法 (支持标准运算符 + - * / % 等)
sum=$(( a + b ))
product=$(( a * b ))
power=$(( 2 ** 8 ))    # 幂运算: 256
echo "sum: $sum, product: $product, power: $power"

# 推荐 2：(( ... )) 复合命令 (常用于自增/自减和条件比较)
(( a++ ))   # a 变为 11
(( b += 5 )) # b 变为 25

# 方式 3：let 命令
let "result = a * 2 + 5"

# 方式 4：expr 命令 (传统外部命令，运算符两侧必须有空格，乘号须转义 \*)
result=$(expr $a + $b)
prod=$(expr $a \* $b)

# 浮点数计算：借助 bc 命令 (Shell 原生仅支持整数)
pi=$(echo "scale=4; 355 / 113" | bc)
echo "PI 近似值: $pi"  # 3.1415
```

## 2. 关系运算符 (数值比较)

> 关系运算符**仅支持整数数值比较**。放在 `[ ]` 单中括号中时，必须使用字母缩写：

| 运算符 | 含义 | 示例 | 结果 (假设 a=10, b=20) |
| :---: | :--- | :--- | :--- |
| **`-eq`** | Equal (等于) | `[ $a -eq $b ]` | false |
| **`-ne`** | Not Equal (不等于) | `[ $a -ne $b ]` | true |
| **`-gt`** | Greater Than (大于) | `[ $a -gt $b ]` | false |
| **`-ge`** | Greater or Equal (大于等于) | `[ $a -ge $b ]` | false |
| **`-lt`** | Less Than (小于) | `[ $a -lt $b ]` | true |
| **`-le`** | Less or Equal (小于等于) | `[ $a -le $b ]` | true |

> **提示**：若在 `(( ))` 中，可直接使用常见的数学符号：`if (( a < b )); then ...`

---

## 3. 字符串运算符

| 运算符 | 说明 | 示例 | 结果 (假设 a="abc", b="xyz") |
| :---: | :--- | :--- | :--- |
| **`=`** 或 **`==`** | 检测两字符串是否相等 | `[ "$a" = "$b" ]` | false |
| **`!=`** | 检测两字符串是否不相等 | `[ "$a" != "$b" ]` | true |
| **`-z`** | 长度为 0 则为真 (Zero) | `[ -z "$empty_str" ]` | 为空时返回 true |
| **`-n`** | 长度不为 0 则为真 (Non-zero) | `[ -n "$a" ]` | true |
| **`$`** | 字符串不为空则为真 | `[ "$a" ]` | true |

> **避坑关键**：在 `[ ]` 中判断字符串时，**变量务必加上双引号 `"$a"`**，防止变量为空时导致语法错误 `[ = "xyz" ]`。

## 4. 布尔与逻辑运算符

- **单中括号 `[ ]`**：使用 `-a` (与)、`-o` (或)、`!` (非)
- **双中括号 `[[ ]]` (推荐)**：支持现代逻辑操作符 `&&`、`||`、`!`

```bash
score=85

# 使用 [[ ... ]] (更安全、不易出错)
if [[ $score -ge 60 && $score -le 100 ]]; then
    echo "成绩及格"
fi

# 使用 [ ... ] (传统写法)
if [ $score -ge 60 -a $score -le 100 ]; then
    echo "成绩及格"
fi
```

## 5. 文件测试运算符 (运维高频)

用于判断文件、目录及权限状态：

| 操作符 | 含义与说明 | 实战常用示例 |
| :---: | :--- | :--- |
| **`-e`** | 文件或目录是否存在 (Exist) | `[ -e "/etc/hosts" ]` |
| **`-f`** | 是否为普通文件 (File) | `[ -f "$config_file" ]` |
| **`-d`** | 是否为目录 (Directory) | `[ -d "$log_dir" ]` |
| **`-s`** | 文件大小是否大于 0 (Size > 0) | `[ -s "$log_file" ]` |
| **`-r`** | 当前用户是否具有**读**权限 (Readable) | `[ -r "$file" ]` |
| **`-w`** | 当前用户是否具有**写**权限 (Writable) | `[ -w "$file" ]` |
| **`-x`** | 当前用户是否具有**执行**权限 (Executable) | `[ -x "./start.sh" ]` |
| **`-L`** | 是否为符号软链接 (Symbolic Link) | `[ -L "/usr/bin/python" ]` |
| **`-nt`** | file1 是否比 file2 更新 (Newer Than) | `[ file1 -nt file2 ]` |
| **`-ot`** | file1 是否比 file2 更旧 (Older Than) | `[ file1 -ot file2 ]` |
