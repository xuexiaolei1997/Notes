# Shell 函数定义与高级应用

通过函数（Function）可以将重复的逻辑模块化，提升 Shell 脚本的可读性与复用性。

---

## 1. 函数定义与调用

### 语法结构
```bash
# 方式 1：标准定义 (推荐)
function_name() {
    # 函数体
    command1
    command2
    return 0  # 可选：返回退出状态码 (0-255)
}

# 方式 2：带 function 关键字
function function_name() {
    # 函数体
}
```

> **调用方式**：直接写函数名即可（如 `function_name`），**不要加括号 `()`**。

---

## 2. 函数参数与 `local` 局部变量

### 2.1 参数传递
在函数内部，参数也是通过 `$1`、`$2`、`$#`、`$@` 等位置变量获取（与脚本顶级参数独立）：

### 2.2 `local` 局部变量 (极其重要)
在函数内部定义的普通变量默认都是**全局变量**，极易污染外部环境。**强烈建议在函数内部使用 `local` 声明局部变量**：

```bash
#!/bin/bash

# 计算两数之和
calculate_sum() {
    # 声明局部变量，防止覆盖外部变量
    local num1=$1
    local num2=$2
    local total=$(( num1 + num2 ))
    
    echo $total  # 通过 stdout 输出结果
}

# 调用函数并捕获输出
result=$(calculate_sum 15 25)
echo "计算结果为: $result"  # 40
```

## 3. 函数返回值处理机制

Shell 函数有两种“返回”方式，使用场景截然不同：

### 方式 A：`return` 状态码 (仅限 0 ~ 255)
`return` 主要用于返回执行状态（类似错误码），通过 `$?` 获取：

```bash
check_service() {
    local service_name=$1
    if pgrep "$service_name" > /dev/null; then
        return 0  # 正常运行
    else
        return 1  # 未运行
    fi
}

# 调用并检查状态
if check_service "nginx"; then
    echo "Nginx 正在运行"
else
    echo "Nginx 未启动！"
fi
```

### 方式 B：通过 `echo` 输出数据流 (捕获任意数据/字符串)
当需要返回字符串、数组或计算数值时，使用 `echo` 输出，外部用命令替换 `$()` 捕获：

```bash
get_ip_address() {
    local ip=$(hostname -I | awk '{print $1}')
    echo "$ip"
}

server_ip=$(get_ip_address)
echo "当前服务器 IP: $server_ip"
```
