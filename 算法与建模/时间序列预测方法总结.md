## 1. 规则基线法：周期因子法

适用于具备**强周期性**且波动相对平稳的业务场景（如零售客流、日活跃用户量 DAU 等），常作为第一代业务 Baseline。

### 核心步骤
1. **确定基础周期**：按周（7天）或按天（24小时）划分周期桶。
2. **计算周期因子 ($Factors$)**：
   $$\text{Factor}_i = \frac{\text{Mean}(Y_i)}{\text{Overall\_Mean}}$$
3. **计算基准值 ($Base$)**：基于近期移动平均计算趋势基准 $Base_t$。
4. **预测输出**：
   $$\hat{Y}_{t} = Base_t \times \text{Factor}_{(t \pmod T)}$$

## 2. 经典统计与线性回归法

将时间周期转化为**时间哑变量 (Dummy Variables)** 或**正弦余弦傅里叶项 (Fourier Terms)**，打破时序强依赖，转为标准回归任务：
- **时间特征编码**：星期几（One-Hot 0-1 变量）、节假日、月份、年内第几周。
- **傅里叶周期编码**：
  $$\sin\left(\frac{2\pi k t}{T}\right), \quad \cos\left(\frac{2\pi k t}{T}\right)$$
- **优点**：计算极快、可解释性极强，同样适合作为坚实的线性 Baseline。

## 3. 传统时序自回归模型 (ARMA / ARIMA / SARIMAX)

基于平稳时序理论的线性预测模型：

$$\Phi(B)(1 - B)^d Y_t = \Theta(B)\epsilon_t$$

### 核心原理与调优规律
- **平稳性检验**：建模前必须通过 ADF (Augmented Dickey-Fuller) 检验序列平稳性。非平稳序列需进行 $d$ 阶差分。
- **自回归项 (AR, $p$)**：消除正相关（平缓衰减）。
- **移动平均项 (MA, $q$)**：消除负相关（突发冲击衰减）。
- **抵消效应**：AR 项与 MA 项的作用在参数过多时会相互抵消，通常精简阶数（$p, q \le 3$）可有效防止过拟合。

```python
from statsmodels.tsa.arima.model import ARIMA

# 拟合 ARIMA(p=1, d=1, q=1)
model = ARIMA(train_series, order=(1, 1, 1))
model_fit = model.fit()
forecast = model_fit.forecast(steps=7)
```

## 4. 时间序列经典分解 (加法/乘法模型与 STL 分解)

将原始时间序列 $Y_t$ 拆解为四个独立分量：
1. **长期趋势分量 ($T_t$, Trend)**：长期的上升或下降趋势。
2. **季节周期分量 ($S_t$, Seasonal)**：固定周期长度与幅度的循环波动。
3. **循环分量 ($C_t$, Cyclical)**：非固定周期的长波波动（常与趋势合并为 $T_t$）。
4. **不规则残差 ($I_t$ 或 $R_t$, Irregular / Residual)**：随机白噪声与异常突发。

### 模型形式选择
- **加法模型 (Additive)**：$Y_t = T_t + S_t + I_t$  
  *适用场景*：季节性波动的**绝对幅度**不随趋势的增长而变化。
- **乘法模型 (Multiplicative)**：$Y_t = T_t \times S_t \times I_t$  
  *适用场景*：季节性波动的**相对比例**随趋势增长呈正比例放大。

### 现代平滑分解：STL (Loess 局部加权回归分解)
相比朴素的移动平均分解，STL 对离群点极其鲁棒，且允许季节周期随时间缓慢演变：

```python
from statsmodels.tsa.seasonal import STL

stl = STL(train_series, period=7, robust=True)
res = stl.fit()
res.plot()  # 分别展示 Trend, Seasonal, Resid
```

## 5. 特征工程 + 机器学习回归 (GBDT / LightGBM / XGBoost)

工业界目前应用**最广泛、效果最稳定**的方案。通过时间滑窗构造丰富的截面特征：

### 核心特征构建清单
- **滞后特征 (Lag Features)**：$Y_{t-1}, Y_{t-2}, Y_{t-7}, Y_{t-14}$（捕获短期自相关与同周期历史值）。
- **滚动统计特征 (Rolling Window)**：最近 3/7/30 天的 `mean`、`std`、`min`、`max`、`skew`、`median`。
- **差分与变动率 (Diff / PCT)**：一阶差分 $Y_{t-1} - Y_{t-2}$、同比变动 $(Y_{t-1} - Y_{t-8}) / Y_{t-8}$。
- **时间日历特征**：小时、星期、月份、是否周末、距离节假日前后天数。

```python
def make_ts_features(df, target_col='y'):
    df = df.copy()
    # 滞后项
    for lag in [1, 2, 3, 7, 14]:
        df[f'lag_{lag}'] = df[target_col].shift(lag)
    # 滚动统计
    df['rolling_mean_7'] = df[target_col].shift(1).rolling(7).mean()
    df['rolling_std_7'] = df[target_col].shift(1).rolling(7).std()
    # 周期同比差分
    df['diff_7'] = df[target_col].shift(1) - df[target_col].shift(8)
    return df.dropna()
```

## 6. 深度学习时序模型

适用于超长序列、海量多变量（Multivariate）协同预测与复杂非线性时序建模：

1. **Seq2Seq + Attention / Transformer**：
   - 典型代表：Informer, Autoformer, PatchTST, TFT (Temporal Fusion Transformer)。
   - 优势：长程依赖捕获能力强，Attention 权重提供变量重要性与时序关注点解释。
2. **时间卷积网络 (TCN - Temporal Convolutional Network)**：
   - 核心：**因果卷积 (Causal Convolution)** 防止未来信息泄露 + **空洞卷积 (Dilated Convolution)** 指数级扩大感受野。
   - 优势：可高度并行化训练，推理延迟明显低于 RNN。
3. **混合架构 (CNN + LSTM + Attention)**：
   - CNN 提取局部形态特征 -> LSTM 学习长短周期时序依赖 -> Attention 进行动态加权聚焦。

## 7. Facebook Prophet：广义加性模型 (GAM)

Prophet 将时间序列拟合看作曲线拟合问题：

$$Y_t = g(t) + s(t) + h(t) + \epsilon_t$$

- $g(t)$：分段线性或 Logistic 增长趋势，支持自动检测变点（Changepoints）。
- $s(t)$：基于傅里叶级数的年/月/周季节性分量。
- $h(t)$：节假日与突发事件冲击效应（支持指定前后影响窗口）。
- **优势**：对缺失值和异常值容忍度极高，参数业务可解释性强。

## 8. 时序转图像与跨模态卷积网络

将一维时间序列编码为二维特征图，借力计算机视觉（CV）中成熟的深层 CNN（如 ResNet）进行特征抽取：
- **格拉姆角场 (GAF - Gramian Angular Field)**：保持时间依赖性与数值大小。
- **马尔可夫转移场 (MTF - Markov Transition Field)**：基于状态转移概率构建矩阵。
- **递归图 (RP - Recurrence Plot)**：通过相空间重构分析时序的周期性与混沌动力学。

## 9. 核心难点、验证策略与防数据泄露最佳实践

> [!CAUTION]
> **绝对不可使用随机 K-Fold 划分时序数据集！** 这会导致“利用未来数据预测过去”的严重数据穿越（Data Leakage）。

### 9.1 正确的时序交叉验证策略
- **滚动窗口切分 (Rolling Window / TimeSeriesSplit)**：
  - Fold 1: Train `[T1 ~ T4]` -> Test `[T5]`
  - Fold 2: Train `[T1 ~ T5]` -> Test `[T6]`
  - Fold 3: Train `[T1 ~ T6]` -> Test `[T7]`
- **净化与阻断 (Purged & Embargoed CV)**：在训练集与测试集之间预留一段空隙（Gap），防止重叠滚动特征导致隐式信息穿越。

### 9.2 多步预测策略选择
1. **递归单步预测 (Recursive Multi-Step)**：用 $t+1$ 的预测值作为下一步的输入特征。易产生误差累积。
2. **直接多步预测 (Direct Multi-Step)**：分别训练独立模型 $M_1, M_2, \dots, M_H$ 直接预测未来各个步长。计算成本较高但无累积误差。
3. **多输出联合预测 (Multi-Output / Seq2Seq)**：直接输出未来 $H$ 步向量（深度学习模型的天然优势）。
