## 1. Step 1：选项目（四类参考）

选题三条标准：

- 足够实质：**涉及多种类型的任务**
- 足够可控：**约 1 小时**内能完成
- 足够心动：**真心想做**

官方四类选题池：

| 类型 | 示例 |
| :--- | :--- |
| **沟通类** | 做一场关于你擅长主题的演示 / 写科普系列文章 / 写提案 pitch / 个人专业简介 |
| **研究类** | 调研某项新兴技术现状 / 分析数据集出建议 / 多方案对比评测 / 历史事件探究 |
| **创作类** | 短篇小说大纲 / 简单网站结构与内容 / 产品服务概念设计 |
| **学习类** | 技能学习计划 / 主题资源合集 / 写教程 / 复习资料 |

> 💡 对你的天然选项：拿 Notes 知识库本身做文章——比如"**为 Academy 学习笔记建一套结构化复习提纲**"（学习类+研究类），正好让学过的东西再加工一遍。

## 2. Step 2：项目愿景与目标

与 Claude 开聊，**让 Claude 提问你**，直到愿景清晰：

- 分享项目想法，邀请 Claude 提问
- 一起打磨出两个答案：
  - **成功长什么样**（What success looks like）
  - **什么会让这个项目对你特别有价值/有意义**

> 💡 又是 Augmentation 式协作：不是"帮我做 X"，而是"问我问题直到我们俩都看清目标"——与 Claude Code L5 的 Plan Mode 澄清提问同构。

---

## 3. Step 3：任务拆解与委派分析

延续 L6 的委派对话，对项目做完整拆解：

1. 一起识别完成项目的**主要任务**
2. **逐个任务**讨论四问：
   - 这块需要什么**技能、知识或 AI 能力**？
   - 哪些部分受益于**人类独特优势**？
   - 哪些部分能**很好利用 AI 能力**？
   - 哪里的**协作影响最大**？
3. 落成**项目计划**：主要任务 + 委派决策
4. **保存计划**——后续课程会回来用它练 Description、Discernment、Diligence

> ⚠️ 官方再次强调：**真对话，而非各自陈述**——挑战彼此的假设、要求澄清、对意外涌现的洞见保持开放。

### 反思三问

1. 与 Claude 的规划对话中涌现了什么洞见？
2. 你预计委派计划中**最具挑战的部分**是什么？
3. 还需要什么信息或技能，能让你更有效地委派给 AI？

## 4. 实战 Cheatsheet

```markdown
### 📋 项目规划与委派速查

#### 1. 选题三标准
多类型任务 + 约 1 小时可完成 + 真心想做

#### 2. 三步流程
① 选题（沟通/研究/创作/学习四类池）
② 愿景：让 Claude 提问直到看清
   "成功长什么样" + "什么让它对你有意义"
③ 拆解：逐任务过四问 → 落成计划 → 保存

#### 3. 逐任务四问
需要什么技能/知识/AI 能力？
哪块受益于人类独特优势？
哪块能用好 AI 能力？
哪里的协作影响最大？

#### 4. 协作姿态
真对话别列清单：挑战假设、要求澄清
保持对意外洞见开放（Augmentation 层）

#### 5. 计划的去向
保存！后续 Description/Discernment/Diligence
三课都会回来用这份计划（实战画布）
```
